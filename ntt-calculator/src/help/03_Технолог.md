# НТТ Калькулятор — инструкция Технолога

Перед началом работы ознакомьтесь с [общей инструкцией](00_Общая_инструкция.md): в ней описаны вход в программу, интерфейс и личные настройки.

> **О рисунках.** В тексте на рисунки даны ссылки вида «(рис. 3)». Файлы рисунков хранятся в папке `img/technolog`, их перечень — в файле [Список_скриншотов.md](Список_скриншотов.md).

## 1. Возможности Технолога

Технолог отвечает за исходные данные, по которым программа составляет расчёты:

- **шаблоны изделий** КНС, ЕМК и КОЛ — описание того, из каких разделов и узлов состоит каждое изделие;
- **каталог узлов** — библиотеку узлов, созданных технологом (что такое узел, см. ниже);
- **справочники** — нормы патрубков, массы труб, массы слоёв на стыках, данные для расчёта корпуса и эллиптических днищ.

Проекты, расчёты, прайс-лист и администрирование Технологу недоступны. После входа сразу открывается экран **«Шаблоны и справочники»**.

> **Главное правило.** Изменения применяются только к **вновь составляемым** расчётам. Уже сохранённые расчёты не изменяются: менеджер увидит сообщение «Справочники изменились после сборки расчёта» или предложение пересчитать расчёт.

### Основные понятия

| Понятие | Значение |
|---|---|
| **Узел** | Готовый фрагмент расчёта, описывающий одну конструктивную часть изделия: например, патрубок, лестницу, перекрытие или теплоизоляцию. Узел содержит перечень материалов и работ, а для каждой строки — формулу, по которой рассчитывается количество |
| **Встроенный узел** | Узел, заложенный в программу разработчиками. Его формулы сверены с прежними Excel-калькуляторами; изменить встроенный узел технолог не может, но может включать его в шаблоны |
| **Узел каталога** | Узел, созданный технологом в разделе «Узлы каталога». Позволяет добавить в расчёт новую конструктивную часть без доработки программы |
| **Параметры узла** | Исходные величины, от которых зависят формулы узла: например, диаметр и количество патрубков |
| **Шаблон изделия** | Набор разделов (например, «Корпус», «Лестница»), в каждый из которых входят узлы. По шаблону программа составляет расчёт для нового изделия |
| **Встроенный шаблон** | Шаблон, заложенный в программу разработчиками (версия 0). Действует, пока технолог не опубликует собственную версию |

## 3. Черновик и опубликованная версия

Шаблоны и узлы каталога изменяются в два этапа: сначала **черновик**, затем **публикация**.

1. Все изменения сначала сохраняются в **черновике**. Черновик не влияет на расчёты.
2. Кнопка «Сохранить черновик» сохраняет изменения без публикации; кнопка «Отменить черновик» отменяет их и возвращает действующую версию.
3. Кнопка «Опубликовать…» открывает окно публикации (рис. 2). В нём кратко указано, чем черновик отличается от действующей версии (сколько узлов добавлено, удалено, перенесено). В поле «Что изменилось» опишите суть изменений и нажмите «Опубликовать». Опубликованная версия становится **действующей** — по ней составляются новые расчёты. Изменить опубликованную версию нельзя, можно только выпустить следующую.
4. В блоке «Версии» перечислены опубликованные версии с датой, автором и пояснением; действующая отмечена надписью «действует». Любую другую версию можно снова сделать действующей (кнопка «сделать действующей», для встроенного шаблона — «сделать действующим») или загрузить в черновик для доработки (кнопка «в черновик») (рис. 3).

Состояние черновика показывается надписью: «есть несохранённые правки», «черновик сохранён, не опубликован» или «черновика нет — правка начнёт его».

## 4. Шаблоны изделий

1. Откройте раздел «Шаблоны изделий» и выберите изделие: **КНС**, **Ёмкость** или **Колодец**.
2. В верхней части экрана указано, какая версия шаблона действует сейчас. Надпись «встроенный шаблон» означает, что действует шаблон, заложенный в программу разработчиками (версия 0).
3. Шаблон состоит из **разделов**, а разделы — из **узлов** (рис. 4):
   - «+ Раздел» — добавить раздел; название раздела можно изменить прямо в поле заголовка;
   - «+ встроенный узел…» и «+ узел каталога…» под каждым разделом — раскрывающиеся списки, из которых узел добавляется в этот раздел (в список узлов каталога попадают только опубликованные узлы);
   - стрелки ↑ и ↓ — переместить раздел или узел выше или ниже;
   - список «→ раздел» в строке узла — перенести узел в другой раздел;
   - кнопка ✕ — убрать узел из шаблона или удалить раздел.

   Встроенные узлы отмечены надписью «встроенный», узлы каталога — «каталог» с номером версии.

   Раздел, в котором есть узлы, удалить нельзя: сначала перенесите узлы в другой раздел или уберите их.

   ![Рис. 4. Редактор шаблона изделия](img/technolog/04-product-template.png)

4. **Связь параметров узла с опросным листом.** Для каждого узла каталога нужно указать, откуда брать значения его параметров. Обычно значение берётся из поля опросного листа: например, параметр «Диаметр» узла «Патрубок» связывают с полем «DN подводящего патрубка». Чтобы задать связь, щёлкните в поле связи нужного параметра (оно появляется под строкой узла), затем раскройте справа панель «Имена и функции» и выберите в ней поле опросного листа — оно будет вставлено в то место, где стоит курсор. Если связь не задана, в поле показана надпись «нет связи» и значение по умолчанию из карточки узла (например, «нет связи – 3000») — именно оно и используется.
5. **Предварительный просмотр.** Справа показан расчёт, который составит шаблон: себестоимость, цена продажи, число строк и строк без цены, суммы по разделам. Раскройте блок «Пример опросного листа», чтобы изменить исходные данные. Строка «К действующей версии» показывает отличия от действующей версии — например, добавленный узел и изменение себестоимости в процентах (рис. 5).

   ![Рис. 5. Связи параметров и предварительный просмотр](img/technolog/05-bindings-preview.png)

6. Опубликуйте шаблон (раздел 3).

**Как вернуться к встроенному шаблону.** Если собственная версия шаблона оказалась неудачной, откройте блок «Версии» и в строке «встроенный» (состав из кода, версия 0) нажмите «сделать действующим». Новые расчёты снова будут составляться по шаблону, заложенному в программу.

**Как создать свой шаблон на основе встроенного.** В блоке «Версии» в строке «встроенный» нажмите «в черновик». В черновике появится полная копия встроенного шаблона, которую можно изменить и опубликовать как собственную версию.

Программа не позволит опубликовать шаблон, если в нём один и тот же узел или раздел встречается дважды, если в него включён неопубликованный или архивный узел каталога либо встроенный узел, относящийся к другому типу изделия.

## 5. Узлы каталога

Узлы каталога позволяют добавить в расчёт новую конструктивную часть без доработки программы. Узел составляется из строк с формулами, а формулы — из параметров узла и функций, уже имеющихся в программе.

### 5.1 Создание узла

1. Откройте раздел «Узлы каталога», введите код нового узла в поле над списком (например, `B5`) и нажмите «+ Узел». Новый узел появится в списке с пометкой «черновик».
2. Заполните карточку узла (рис. 6):
   - **Код** — краткое обозначение узла: начинается с латинской буквы, далее могут следовать буквы, цифры, точка или дефис; не более 16 знаков (например, `B5`). Коды встроенных узлов использовать нельзя; после создания узла код изменить невозможно;
   - **Рубрика**, **Название**, **Описание**;
   - **Включается, если** — условие, при выполнении которого узел входит в расчёт (например, `d >= 2000` — только для корпусов диаметром от 2000 мм). Для отдельной строки узла можно задать собственное условие в колонке «Условие»; значение «всегда» означает, что строка включается без условий.
3. **Параметры** (кнопка «+ параметр»): имя, подпись, тип значения (число, «да/нет» или текст), значение по умолчанию, единица измерения.
4. **Строки** (кнопка «+ строка»): вид строки (материал или операция), категория, наименование, количество (формула), коэффициент трудоёмкости «k ФОТ» (для операций), условие, примечание.
   - Категорию выбирайте только из предложенного списка. По категории, наименованию и единице измерения программа ищет цену в прайс-листе, поэтому наименование нужно указывать **в точности так, как в прайс-листе**.
   - Для каждой операции программа автоматически добавляет строку оплаты труда (ФОТ). Трудоёмкость рассчитывается как масса детали, умноженная на коэффициент: 0,28 — для механической формовки, 0,56 — для ламинирования, 1,0 — для остальных операций.
   - Не используйте в наименованиях символ `~`.
5. **Формулы** количества составляются с помощью панели «Имена и функции» в правой нижней части экрана. В ней перечислены параметры узла и функции, знакомые по Excel: ОКРВВЕРХ, ОКРУГЛ, ОКРВНИЗ, МАКС, МИН, ЕСЛИ, И, ИЛИ, НЕ, ПИ, КОРЕНЬ и другие. Щёлкните в поле формулы, а затем на нужном элементе панели — он будет вставлен в место курсора (рис. 7). В формулах можно использовать арифметические действия, например `d / 1000 * 42`.
6. Проверьте результат в блоке **«Предпросмотр»**: задайте значения параметров и посмотрите, какие строки, количества и суммы даст узел (строки без цены выделены красным). Затем опубликуйте узел. Включить в шаблон можно только опубликованный узел.

![Рис. 6. Карточка узла каталога](img/technolog/06-node-editor.png)

![Рис. 7. Панель «Имена и функции»](img/technolog/07-formula-palette.png)

### 5.2 Архив

Кнопка «В архив» убирает узел из списка доступных для добавления в шаблоны. Узел, входящий в действующий шаблон, перенести в архив нельзя. Кнопка «Вернуть из архива» восстанавливает узел. Если узел ещё ни разу не публиковался, отмена его черновика удаляет узел из каталога полностью.

## 6. Справочники

Справочники редактируются построчно (рис. 8). Над таблицей можно выбрать диаметр, чтобы показать только относящиеся к нему строки. Чтобы изменить строку, исправьте значения и нажмите значок дискеты 💾 в конце строки; значок × удаляет строку. Новую строку заполняют в последней, пустой строке таблицы и добавляют кнопкой «+». Изменения сохраняются сразу, без черновика, и применяются к вновь составляемым расчётам. Поля, отмеченные звёздочкой, обязательны для заполнения.

![Рис. 8. Справочник «Веса труб GRP»](img/technolog/08-pipe-weights.png)

| Справочник | Строка определяется по | Поля |
|---|---|---|
| Нормы патрубков | диаметру (DN) | наружный диаметр, минимальная длина, общая масса формовки*, h1, s1, масса формовки фланца, болт, количество болтов |
| Веса труб GRP | диаметру, классу давления трубы и кольцевой жёсткости | толщина стенки (мм), масса погонного метра (кг/пм)* |
| Мс на стыке | диаметру и давлению (атм) | масса слоёв на стыке (кг)*, размеры H, S, X (мм) |
| Матрица корпуса | диаметру и длине | масса (кг)*, толщина (мм) |
| Эллиптические днища | диаметру и длине | масса (кг)* |

**Особенности справочников:**

- **Веса труб.** В справочнике указывается **класс давления самой трубы** (0,6; 1; 1,6), а не давление из опросного листа (у КНС оно равно 0,1). Изделия классов 0,1 и 0,4 программа рассчитывает по трубе класса 0,6. Сочетание диаметра, класса давления и жёсткости не может повторяться: если такая строка уже есть, измените её.
- **Мс на стыке** (масса формованных слоёв на стыке). Для каждого диаметра расчёт использует строку с **наименьшим давлением** (сейчас это 4 атм, то есть 0,4 МПа), поскольку изделия безнапорные. Эта строка отмечена красной стрелкой ◀; при наведении на неё указателя мыши появляется подсказка «Эту строку читает расчёт» (рис. 9). Строки с другими давлениями хранятся для справки.
- Все изменения справочников фиксируются в журнале действий.

## 7. Рекомендуемый порядок внесения изменений

1. Внесите изменения в черновик шаблона или узла (либо в справочник).
2. Проверьте результат в предварительном просмотре на типовом опросном листе и сравните с действующей версией.
3. Опубликуйте изменения с понятным пояснением: что изменено и по какой причине.
4. Если изменения затрагивают текущие расчёты, сообщите об этом менеджерам — им потребуется пересчитать расчёты.
5. Если после публикации обнаружена ошибка, сделайте действующей предыдущую версию.
