# НТТ Калькулятор — инструкция Закупщика

В программе роль Закупщика называется **«Снабженец»**. Перед началом работы ознакомьтесь с [общей инструкцией](00_Общая_инструкция.md): в ней описаны вход в программу, интерфейс и личные настройки.

> **О рисунках.** В тексте на рисунки даны ссылки вида «(рис. 3)». Файлы рисунков хранятся в папке `img/buyer`, их перечень — в файле [Список_скриншотов.md](Список_скриншотов.md).

## 1. Возможности Закупщика

- **Прайс-лист** — просмотр, изменение цен и поставщиков, загрузка цен из файла Excel и выгрузка прайс-листа в Excel;
- **Заявки на закупку** — список расчётов и заявка на закупку по каждому из них с выгрузкой в Excel.

Проекты, расчёты, опросные листы, выпуск КП и шаблоны Закупщику недоступны. После входа открывается **прайс-лист**; в меню слева доступны пункты «Заявки на закупку» и «Прайс-лист».

## 2. Прайс-лист

### 2.1 Как прайс-лист используется в расчётах

Цена для строки расчёта определяется по сочетанию трёх признаков: **категория, наименование и единица измерения**. Одно и то же наименование может встречаться с разными единицами измерения (например, «шт» и «м») — это разные позиции прайс-листа. Если подходящая позиция не найдена или у неё не указана цена, строка расчёта остаётся **без цены**, и выпустить КП по такому расчёту нельзя.

Каждое изменение цены и каждая загрузка цен из файла создают **новую версию прайс-листа** (обозначается «НН v1», «НН v2» и т. д.). В выпущенном КП сохраняются цены той версии прайс-листа, по которой оно было рассчитано, поэтому последующие изменения прайс-листа на выпущенные КП не влияют.

### 2.2 Просмотр

На экране прайс-листа (рис. 1):

- слева — **категории** (всего 16, например «Металлопрокат», «Метизы», «Запорная арматура», «Насосы, АТМ», «Датчики», «Шкафы») с числом позиций в каждой. Отметьте флажками одну или несколько категорий, чтобы показать только их; ссылка «все» отменяет отбор;
- строка поиска по наименованию и поставщику (можно ввести несколько слов через пробел);
- кнопки-фильтры **«без цены»** и **«с замечаниями»** с числом таких позиций, а также кнопка «Сбросить фильтры»;
- в правом верхнем углу — кнопки «Экспорт в xlsx» и «Импорт из xlsx» и надпись «найдено N из M»;
- таблица с колонками: наименование, единица измерения, цена (₽), поставщик, дата изменения. Позиции сгруппированы по категориям. Чтобы отсортировать таблицу, щёлкните по заголовку колонки.

Позиции, требующие внимания, отмечены: **«нет цены»**, нулевая цена, расхождение с ценой без скидки, цена листового материала указана за штуку вместо квадратного метра. Проверяйте такие позиции в первую очередь — быстрее всего их найти фильтрами «без цены» и «с замечаниями».

### 2.3 Изменение цены и поставщика

1. Нажмите значок карандаша ✎ в правой части строки или **дважды щёлкните** по строке.
2. Введите цену (числом) и при необходимости поставщика.
3. Нажмите кнопку ✓ или клавишу **Enter**, чтобы сохранить изменения; кнопку × или клавишу **Esc** — чтобы отменить их (рис. 2).

![Рис. 2. Изменение цены в строке прайс-листа](img/buyer/02-price-edit.png)

При изменении цены создаются новая версия прайс-листа и запись в истории изменения цен. Изменение только поставщика новую версию не создаёт.

### 2.4 Загрузка цен из Excel

1. Нажмите «Импорт из xlsx» и выберите файл (размером не более 25 МБ). Цены считываются с листа **«НН»**, оформленного по образцу основного Excel-калькулятора.
2. Сначала программа только **проверяет файл**, ничего не изменяя в прайс-листе, и показывает отчёт о проверке (рис. 3). В отчёте указано:
   - сколько позиций будет добавлено;
   - у скольких позиций изменится цена;
   - у скольких позиций изменятся другие сведения (например, поставщик);
   - сколько позиций останется без изменений;
   - у каких позиций в файле не указана цена — для них сохранится прежняя цена;
   - какие позиции прайс-листа отсутствуют в файле — такие позиции **не удаляются** и остаются в прайс-листе;
   - какие наименования исправлены автоматически: лишние пробелы, латинские буквы вместо русских (например, «ГOCT» с латинской «O» или «108x8» с латинской «x»);
   - какие строки пропущены и какие позиции повторяются. Если позиция встречается в файле несколько раз, используется первая строка (так же, как в функции ВПР в Excel); повторяющиеся строки рекомендуется удалить из файла.
3. Проверьте отчёт и нажмите **«Применить импорт»** или «Отмена». Если изменений нет, программа сообщит об этом.
4. После применения появится сообщение «Прайс обновлён: версия vN».

Строки, в наименовании которых есть символ `~`, не загружаются.

![Рис. 3. Отчёт о проверке файла перед загрузкой](img/buyer/03-import-report.png)

### 2.5 Выгрузка в Excel

Кнопка «Экспорт в xlsx» сохраняет прайс-лист в файл Excel с двумя листами (рис. 4):

- **«НН»** — прайс-лист, оформленный по образцу основного Excel-калькулятора; этот лист можно исправить и снова загрузить в программу;
- **«Проверка»** — позиции без цены и позиции с сомнительными ценами.

Рекомендуемый порядок обновления цен: выгрузить прайс-лист → внести изменения в Excel → загрузить файл → проверить отчёт → применить изменения.

![Рис. 4. Выгруженный прайс-лист в Excel](img/buyer/04-prices-excel.png)

## 3. Заявки на закупку

### 3.1 Список заявок

На экране «Заявки на закупку» приведены все расчёты: наименование изделия, его тип (KNS — насосная станция, EMK — ёмкость, KOL — колодец), автор расчёта и дата последнего изменения. Над списком расположены строка поиска по наименованию изделия, фильтр по типу изделия и кнопка «Сбросить». Чтобы открыть заявку, щёлкните по строке (рис. 5).

![Рис. 5. Список заявок на закупку](img/buyer/05-purchases-list.png)

### 3.2 Заявка

В заявку входят все покупные позиции расчёта, то есть все категории, кроме «Собственное производство», «Работы» и «ФОТ» (фонд оплаты труда):

| Колонка | Содержание |
|---|---|
| № | Порядковый номер строки |
| Категория, наименование, единица измерения | Из расчёта |
| Количество | Количество по расчёту с учётом числа корпусов в заказе |
| Бюджетная цена, бюджетная стоимость | Ориентировочная цена из расчёта и сумма |
| Дата закупки, отметка об исполнении | Заполняются в выгруженном файле |

В конце таблицы приводится строка **«ИТОГО»**, а в верхней строке экрана — число позиций и общая сумма. Если у некоторых позиций нет цены, над таблицей выводится предупреждение, например: «4 закупаемых строки без цены — их стоимость в заявке равна нулю. Укажите цену позиции в прайсе». В этом случае добавьте или исправьте позиции в прайс-листе (раздел 2.3) и попросите менеджера пересчитать расчёт.

Кнопка «Выгрузить xlsx» в правом верхнем углу сохраняет заявку в файл Excel (рис. 6). Ссылка «← Заявки» возвращает к списку заявок.

![Рис. 6. Заявка на закупку](img/buyer/06-purchase-request.png)

> Заявка на закупку — внутренний документ с ориентировочными ценами; это не цена для заказчика. Заявка всегда составляется по текущему состоянию расчёта.

## 4. Часто задаваемые вопросы

| Вопрос | Ответ |
|---|---|
| Я изменил цену, но в расчёте осталась прежняя | Расчёт хранит цены, действовавшие на момент его составления. У менеджера такие строки будут отмечены как «цена изменилась», и он сможет пересчитать расчёт |
| Удаляет ли загрузка из файла позиции, которых нет в файле? | Нет. Такие позиции остаются в прайс-листе без изменений |
| Почему в расчёте строка «без цены», хотя позиция есть в прайс-листе? | Не совпадает категория, наименование или единица измерения — в том числе пробелы и регистр букв. Сверьте написание с наименованием в расчёте |
| Можно ли открыть сам расчёт? | Нет. Закупщику доступна только заявка на закупку по расчёту |
