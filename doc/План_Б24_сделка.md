# Калькулятор в карточке сделки Битрикс24

План интеграции (развитие ТЗ §10.2–10.5). Вход из портала уже работает
(`routes/bitrix.routes.ts`); здесь — вкладка «Калькулятор» в сделке, связь
проектов со сделкой и отправка КП в ленту сделки.

## Решения

- **Сумма КП в сделку не пишется.** По одной сделке бывает много КП с разными
  суммами, и какое станет итоговым, заранее не известно. Никакого
  `crm.deal.update` и UF-поля «Стоимость по расчёту» (отход от ТЗ §10.4).
  Каждое КП — отдельный комментарий в ленте сделки с PDF; во вкладке видны все.
- **Работаем ключом сотрудника**, открывшего калькулятор (OAuth локального
  приложения), а не вебхуком: записи в ленте — от его имени, чужих сделок,
  закрытых ему в портале, калькулятор не покажет. Вкладку в карточку может
  добавить только приложение (`placement.bind`), вебхук — нет.
- **Событий портала нет**: сервер в локальной сети, Битрикс до него не
  достучится. Всё — по запросу из браузера сотрудника.
- Одна сделка — сколько угодно проектов, у проекта — не больше одной сделки.
- Заказчик — из компании сделки, нет компании — из контакта. Адрес объекта —
  адрес компании, правится вручную.
- Создавать расчёт из сделки и привязывать проекты: ADMIN, MANAGER, ENGINEER.
  Остальные видят вкладку только для чтения.

## Права приложения в портале

`user_basic` (почта для привязки учётки), `crm` (сделка, компания, контакт,
комментарий в ленте), `placement` (вкладка). «Диск» не нужен — PDF уходит
вложением комментария. Выданы 2026-11-04.

Сотруднику в его роли CRM нужно чтение сделки и право её комментировать.

## Ключи сотрудников

Портал при каждом открытии приложения присылает `AUTH_ID` (живёт час) и
`REFRESH_ID` (28 дней). Они хранятся в `B24Token` по учётке; когда ключ
истёк, сервер продлевает его на `oauth.bitrix.info` с `client_secret`.
Продлевать ключ, не зная `client_secret`, нельзя, поэтому сам `refresh` в базе
без `.env` бесполезен. Отвязка учётки от Битрикс24 и её удаление стирают ключи.
Не открывал калькулятор из портала 28 дней — фоновая отправка КП не пройдёт,
пока не откроет снова.
