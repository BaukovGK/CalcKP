**Назначение документа:** самодостаточное задание на проработку интерфейса и дизайна. Содержит весь контекст — внешние документы для работы не требуются (первоисточники: `ТЗ.md`, `Механика_калькулятора.md`, `Библиотека_компонентов.md`).

Из артефактов §11 закрыты пп. 1–3 частично; **не проработаны**: Dashboard, Гидравлика (график), Прайс с diff, Заявка на закупку, Каталог компонентов, Админ, разделение ролей. Этот бриф остаётся заданием для следующих сессий по оставшимся экранам; визуальный язык — наследовать из хендоффа (Archivo, радиус 0, палитры и токены README).

## 1. Продукт в одном абзаце

B2B-инструмент расчёта себестоимости и цены промышленных изделий из стеклокомпозита (насосные станции, ёмкости, колодцы) для завода ООО «НТТ». Заменяет Excel-книгу на 19 листов. Инженер заполняет опросный лист изделия — система материализует спецификацию из сотен строк (материалы, операции производства, труд) с формульными количествами и ценами из прайса; инженер точечно «тюнингует» строки; менеджер утверждает; итог уходит в Битрикс24. Ключевое ощущение: **управляю изделием, а не таблицей**.

## 2. Пользователи

| Роль | Портрет | Основной сценарий | Частота |
|---|---|---|---|
| ENGINEER | Инженер-сметчик, глубоко знает изделие, привык к Excel | ОЛ → расчёт → тюнинг → на проверку | ежедневно |
| MANAGER | Руководитель направления | Проверка расчёта, рентабельность, утверждение/возврат | несколько раз в неделю |
| BUYER | Закупщик | Актуализация прайса, заявка на закупку | еженедельно |
| TECHNOLOG | Технолог-методолог | Редактор каталога компонентов и шаблонов (фаза 3) | редко, вдумчиво |
| ADMIN | ИТ/руководство | Пользователи, аудит | редко |

Все — русскоязычные, десктоп, большие мониторы, многочасовые сессии. Мобильная версия не требуется; минимум — читаемость на ноутбуке 1366px.

## 3. Контексты запуска (жёсткое ограничение)

1. **Standalone SPA** — полноэкранный режим.
2. **Iframe внутри Битрикс24** (облако): страница приложения и вкладка в карточке сделки. Следствия: нельзя рассчитывать на всю высоту вьюпорта (resize через BX24 API), нет своих top-level навбаров, дублирующих Б24, нет third-party cookies, вёрстка должна жить в ~900–1200px ширины. Одна и та же вёрстка обслуживает оба контекста — навигация сворачиваемая.

Темизация: светлая и тёмная темы через CSS custom properties (`data-theme` на `<html>`), тёмная — по умолчанию. Все цвета — только токенами.

## 4. Карта экранов

```
Login (только standalone; в Б24 — SSO без экрана)
└─ Dashboard: проекты + поиск
   └─ Проект: карточка + сетка единиц оборудования
      └─ Опросный лист (модал-визард при создании единицы)
      └─ КАЛЬКУЛЯТОР ← главный экран, 80% времени
         ├─ Гидравлический расчёт (подэкран/вкладка)
         ├─ Заявка на закупку (view)
         └─ История версий / снапшоты
Прайс-лист (BUYER/ADMIN)
Каталог компонентов и шаблонов (TECHNOLOG, фаза 3)
Админ: пользователи + аудит
```

## 5. Ключевые экраны

### 5.1 Опросный лист (визард)

Анкета изделия, 30–50 полей, секции: общие данные → корпус → смола → патрубки → насосное оборудование → доп. оборудование → вентиляция/теплоизоляция. Требования:

- Прогрессивное раскрытие: флаг «нет» сворачивает зависимые поля (например, «Теплоизоляция: нет» прячет глубину).
- **Live-расчёты рядом с полями:** при вводе расхода и уровней система тут же показывает Vэф/Vмин/Vраб и рекомендуемую глубину подземной части (`Нподз = 11 600 мм`) с возможностью принять или ввести свою. Это фирменный момент продукта — визуально выделить.
- Поля с ЕИ-переключателем (л/с | м³/ч | м³/сут).
- Обязательные поля помечены; черновик сохраняется незавершённым.
- Финал: кнопка «Создать расчёт» с превью: тип изделия, габарит «3000×11900 мм», список включённых блоков.

### 5.2 Калькулятор (главный экран)

Трёхзонная компоновка: слева — дерево сборок (навигация), центр — таблица строк активной сборки, справа/снизу — закреплённая панель итогов.

**Дерево сборок** (7 разделов для НС): каждая с флагом-переключателем включения, подытогом и бейджем проблем. Выключенная сборка — «призрак» (видна, полупрозрачна, в итог не входит). Вложенность до 3–4 уровней: Сборка → Компонент → Строки.

**Таблица строк** — сердце продукта. Колонки: категория · наименование · кол-во · ЕИ · цена · сумма · примечание. Плотность высокая (в реальных расчётах 300–450 строк), но каждая ячейка кол-ва и цены несёт **индикацию источника**:

| Состояние | Индикация | Смысл |
|---|---|---|
| Расчётное значение | серое/обычное | посчитано формулой из ОЛ |
| Ручной override | синий + точка/маркер | инженер переопределил; ховер показывает расчётное значение и кнопку «↺ вернуть» |
| Нет цены | красная строка | цены нет в прайсе и не введена вручную; сумма 0 |
| Конфликт | янтарный значок | ОЛ изменился, расчётное значение «уехало» из-под override; действия: оставить / сбросить |
| Выключено | призрак | сборка/узел выключен |
| ФОТ-спутник | вложена под родителя, слегка отступлена | производная строка; кол-во read-only с override |

- Ввод количества принимает арифметику: `1.55*2+2.88*2` — сохраняется выражение, показывается результат.
- Счётчик проблем в шапке: «3 строки без цены, 1 конфликт» — клик фильтрует.
- Добавление строк: из каталога компонентов (поиск по 1000+ позиций прайса с автодополнением по категории) или свободная строка.
- Типовое место ручного ввода — цена трубы корпуса (договорная): строка «Труба СК/НПС-К 3000-0,1-10000» рождается красной, подсказка «указать стоимость трубы».

**Панель итогов** (всегда видна): Материалы · Труба/муфта · Формовка · Работы ФОТ · Прочие → **Себестоимость 11 603 440 ₽** → наценка [0,43] (редактируемая) → **Цена продажи 16 593 000 ₽** → рентабельность 30,1%. При тираже N≥2 — две колонки «за 1 корп. / за N корп.». Изменение любой строки анимированно обновляет итог — мгновенная обратная связь.

**Топбар:** статус (DRAFT/CALC/REVIEW/APPROVED), кнопки перехода по ролям, версия прайса, экспорт (КП, Заявка), снапшоты. Красные строки блокируют «На проверку» — состояние кнопки объясняет причину.

### 5.3 Гидравлический расчёт

Форма (расход, отметки, диаметры) + **график**: кривая системы и кривая насоса (паспортные точки — редактируемая мини-таблица), рабочая точка на пересечении подсвечена (Q=12,6 л/с, H=12,9 м). Кнопка «Применить насос к расчёту» → марка и параметры уходят в ОЛ и раздел «Оборудование».

### 5.4 Прайс-лист

Таблица ~1050 позиций: категория (14 значений, фильтр-чипы) · наименование · ЕИ · цена · поставщик · дата изменения. Inline-редактирование цены (BUYER). Версионирование: переключатель версий + diff-режим «что подорожало» (старая/новая цена, дельта %). Импорт из Excel с отчётом «обновлено/создано/пропущено».

### 5.5 Заявка на закупку

Read-only представление закупаемых строк расчёта: № · категория · наименование · ЕИ · кол-во · бюджетная цена · стоимость · дата закупки · отметка исполнения. Группировка по категориям, экспорт в Excel/PDF, печатная форма с реквизитами ООО «НТТ».

### 5.6 Каталог компонентов (TECHNOLOG, фаза 3)

Библиотека ~26 узлов с тегами (корпус / конструкции / системы / оборудование). Карточка узла: параметры, состав строк (тип МАТЕРИАЛ/ОПЕРАЦИЯ, формула по имени из реестра, k ФОТ), варианты, флаги. **Предпросмотр-материализация:** ввёл тестовые параметры (DN=2000, L=5000) — увидел готовые строки с ценами. Публикация «черновик → активен». Конструктор шаблона: дерево сборок drag-n-drop из каталога + биндинги параметров на поля ОЛ.

## 6. Статусная модель (виден каждому экрану)

```
DRAFT → CALC → REVIEW → APPROVED        REVIEW → CALC (возврат)
                                        любой → REJECTED (ADMIN)
```

APPROVED — расчёт заморожен (снапшот): вся таблица read-only, визуально «запечатан». Красные строки блокируют CALC→REVIEW.

## 7. Реальные данные для мокапов

Использовать в макетах реальную фактуру (из действующих расчётов):

- Изделие: «КНС 3000×11900 мм (подземная часть 11 600 мм), 25,13 л/с», заказчик АО «ГК «ЕКС», объект «ГКБ №52, ул. Пехотная, 3».
- Строки: «Труба СК/НПС-К 3000-0,1-10000» — 11,6 м — цена вручную; «Придание изделию товарного вида» — 26,8 чел.ч × 1207,8 ₽; «Механическое формованное дно» — 262,8 кг × 214,4 ₽; «Ламинирование дна к фальшполу» — 78,9 кг × 310,2 ₽; «ФОТ» — 73,6 чел.ч; «Задвижка чугунная клиновая DN150» — 5 шт; «Насос VSL.100.55.4.5.0D» — 3 шт; «Поплавковый выключатель, кабель 10 м» — 4 шт × 6000 ₽.
- Категории: Собственное производство, ФОТ, Метизы, Металлопрокат, Запорная арматура, Насосы/АТМ, Датчики, Шкафы…
- Итоги: себестоимость 11 603 440 ₽ → цена 16 593 000 ₽, наценка 0,43, рентабельность 30,07%.
- Наименования длинные («Фланец 50-10-01-1-В-12Х18Н10Т ГОСТ 33259-2015») — колонка наименования доминирует, обрезка с тултипом недопустима для печатных форм.

## 8. Визуальные требования

- Числа: разряды пробелами (11 603 440), рубли без копеек в итогах, 2 знака в ценах; моноширинные цифры (tabular-nums) во всех таблицах.
- Высокая плотность без клаустрофобии: строка таблицы ~32–36px, зебра или разделители на выбор дизайнера.
- Цветовой язык состояний (§5.2) — единственный обязательный цветовой контракт; остальная палитра свободна, но сдержанно-индустриальная (это инструмент завода, не маркетинг).
- Обе темы равноправны; проверка контраста WCAG AA в обеих.
- Язык интерфейса — русский; терминологию не «упрощать» (ОЛ, ФОТ, СН/PN/SN, чел.ч — профессиональный словарь пользователей).
- Иконография: минимальная, состояния важнее иконок.

## 9. Инвентарь UI-компонентов (для дизайн-системы)

Таблица-дерево с inline-редактированием · ячейка с двойным источником значения (расчёт/override) · панель итогов с live-обновлением · статус-бейдж и статус-переходы · счётчик/фильтр проблем · визард-форма с live-подсказками · график двух кривых с рабочей точкой · diff цен · чипы-фильтры категорий · модал (закрытие по фону отключаемо) · контекстное меню · переключатель темы · тосты/подтверждения · печатные формы (КП, Заявка).

## 10. Приоритеты и антицели

**Приоритеты:** 1) читаемость и скорость работы с таблицей 300+ строк; 2) мгновенная связь «правка → итог»; 3) прозрачность источника каждого числа (доверие — главная валюта против Excel); 4) работа в iframe Б24 без деградации.

**Антицели:** не делать «красивый дашборд с графиками» — это рабочий стол сметчика; не прятать данные за кликами (Excel-пользователи привыкли видеть всё); не изобретать собственную навигацию внутри вкладки Б24.

## 11. Ожидаемые артефакты дизайн-сессии

1. UI-kit: токены (цвета двух тем, типографика, отступы), состояния ячеек и строк из §5.2.
2. Мокапы: Калькулятор (основной кейс + все состояния строк + APPROVED read-only), Опросный лист (2–3 секции с live-подсказками), панель итогов с тиражом, Прайс с diff, Гидравлика с графиком, Dashboard.
3. Флоу: «от ОЛ до утверждения» и «закрыть красные строки».
4. Адаптация той же вёрстки под iframe Битрикс24 (1000px).
