## 2. Архитектура книги и поток данных

```
Опросный лист (ОЛ_НАСОСНАЯ_СТАНЦИЯ / ОЛ_ЕМКОСТИ / ОЛ_КОЛОДЦА)   ← ручной ввод
        │  (+ встроенный расчёт объёмов Vэф/Vмин/Vраб и глубины Нподз)
        ▼
Калькулятор (КНС / ЕМК / колодца)  ← построчная спецификация BOM + труд
        │   цены ← НН (прайс)
        │   веса ← «Вес трубы, ПЭ трубы»
        │   нормативы ← «Для расчетов», «Вспомогат. таблицы», «для шапки»
        │   списки/enum ← «Списки»
        ▼
Итоговый блок (себестоимость → наценка 43% → цена продажи)
        ▼
«Заявка» — закупочный документ-view (агрегация непустых строк калькулятора)
```

Параллельный контур: «Гидравл. расчет» (подбор насоса: кривая системы × кривая насоса) → марка/кол-во насосов в ОЛ → раздел 7 калькулятора.

Листы книги: Инструкции, Содержание, Списки, Инструкции1, ОЛ_КОЛОДЦА, Калькулятор колодца, ОЛ_ЕМКОСТИ, Калькулятор ЕМК, для шапки, ОЛ_НАСОСНАЯ_СТАНЦИЯ, Калькулятор КНС, Заявка, Вспомогат. таблицы, Цветовая библиотека, Гидравл. расчет, Для расчетов, Вес трубы/ПЭ трубы, НН, Справка по подбору АШУ Омега.

## 3. Универсальный «движок строки» (общий для всех трёх калькуляторов)

Каждая товарная/рабочая строка имеет одинаковый набор колонок:

| Кол. | Назначение |
|---|---|
| B | № раздела (1, 1.1, 2 …) |
| C | **Категория** (enum из Списки!AG2:AG17 — 16 значений) |
| D | Наименование (часто формула-CONCATENATE из параметров: `"Труба СК/НПС-К "&DN&"-"&PN&"-"&SN`) |
| E | Доп. параметр / подвариант |
| F | Флаг «Закупка»: `да`, если категория ∉ {Собственное производство, Работы, ФОТ} |
| G | Вес, кг/пм |
| H | **Кол-во за 1 ед. — ручной override** |
| I | Кол-во — **расчётная формула** (геометрия/норматив) |
| J | Общее кол-во: `IF(H=""; I; H)` × флаги включения раздела × кол-во корпусов |
| K | ЕИ (м, шт, кг, м², чел. ч) — определяет физический смысл: кг = формовка, чел.ч = труд |
| L | **Цена — ручной override** |
| M | Цена из прайса: `IFERROR(IF(L<>"";""; VLOOKUP(C&D&K; НН!A:J; 10)); "")` |
| N | Сумма: `IF(L=""; M*J; J*L)` |
| O | Примечание |
| P, Q | МТО / Логистика (заголовки есть, в расчётах не используются) |

**Три ключевых паттерна:**

1. **Двухканальный override.** Количество: расчёт в I, ручной ввод в H перекрывает. Цена: прайс в M, ручной ввод в L перекрывает (для трубы/муфты цена почти всегда вводится вручную — уникальна под проект).
2. **Составной ключ прайса** = `Категория & Наименование & ЕИ` (конкатенация без разделителя) → колонка A листа НН; цена — колонка J (10-я).
3. **ФОТ-строки парами.** К каждой производственной операции добавляется строка ФОТ; трудоёмкость = масса операции (кг) × коэффициент: **0,28 чел.ч/кг** — механическая формовка (`*мех*` в наименовании), **0,56** — ламинирование (`*ламин*`), **1,0** — ручная формовка и отдельные виды ламинирования. `J = ROUNDUP(масса×коэф; 1)`; цена чел.ч = ставка ФОТ из НН.

Разделы включаются/выключаются флагами «Да/Нет» (ячейка C у заголовка раздела или поле ОЛ) — при «нет» J-количества обнуляются.

### 4.3 Примеры расчётных формул количеств
- Труба корпуса: `I14 = L/1000` м; вес `= I14 × INDEX(ВесТрубы; MATCH("DN;PN;SN"); 3)`
- Придание товарного вида: `I15 = DN/1300 × J14` чел.ч
- Масса формованного дна: `I22 = π·((DN+300)/2000)²·0,01·1850 + ((DN/1000)²·π·0,008·1850)/4` (плотность ламината 1850 кг/м³)
- Ламинирование детали к корпусу: `масса_детали × 3/10` кг ламината
- Верхнее перекрытие: `π·((DN+300)/2000)²·0,006·1850 − масса_горловины×кол-во_люков`
- Теплоизоляция: вертикаль `π·(DN/1000)·(глубина_ТИ/1000)` м²; крышка `π·(DN/2000)²`; защитный слой `S·0,005·1850` кг
- Прорезка отверстия: `Ø·π/1000 × 0,5 × кол-во` чел.ч (0,5 чел.ч на 1 м окружности)
- Подготовка трубы: `(DN/(200·6))·L` чел.ч
- Направляющие насосов: `L×(раб+рез)×2`
- Анкеры: `(глубина·1000·9,8·π·Дн²/4)/27500` (27 500 Н на 1 анкер М16)

### 4.4 Условная логика (флаги)
Дробилка↔корзина (ОЛ!E46, взаимоисключающие), теплоизоляция (E72+глубина E73), фальшпол (C50), задвижка на подводящем (E47), аварийный трубопровод (I47), лестница и её материал (C119/C121), тип крышки СК/металл (E139), МВК-комплект — поручень, откидные люки, перехватывающее устройство, нерж. вентиляция (E27), датчики/расходомер/ШУ (I64–I66), насосы (E55+E56+E57), петли простые/усиленные (DN<2000).

## 5. Калькулятор ЕМК — отличия от КНС

- Габариты подбираются автоматически из листа **«для шапки»** по ключу `Расположение&Установка&Шахта` (8 комбинаций): длина трубы из объёма `CEILING(4V/(π·(D/1000)²)·1000; 100)`.
- Материал по среде: `D8 = IF(тип="Химстойкая"; "СК/ВЭС"; "СК/НПС")`.
- **Днище — переключатель «Новый/Старый способ»**: горизонтальная ёмкость → эллиптические днища (объём `L5 = π·(DN/1000)³/15`, длина трубы +1,5 м; массы из матрицы «Для расчетов»); вертикальная → плоское/формованное.
- Есть разделы «Напорный трубопровод» и «Насосное оборудование» (когда ёмкость с насосами), гидравлический блок Vэф/Vмин/Vраб прямо в ОЛ_ЕМКОСТИ.
- ОЛ ёмкости: объём, DN, PN, SN, расположение (гориз./верт.), установка (наземная/подземная/в помещении), шахта обслуживания (d, h), патрубки, насосы, дробилка/корзина, ШУ+датчики, вентиляция, теплоизоляция.

- Упрощённый состав: корпус (труба, дно, патрубки, горловина — усл. по E26, фальшпол, теплоизоляция, петли), корзина, лестница, перекрытие, вентстояк, крепёж, задвижки. Без насосов и напорного трубопровода.

## 7. Гидравлический расчёт (лист «Гидравл. расчет»)

Полуручной лист. Входы: расход на 1 нитку `Q = приток/(3,6·кол-во ниток)`, отметки (планировка, ввод, вывод, мин. уровень воды, диктующая точка), внутренние диаметры и длины напорного трубопровода в КНС и вне.

- Скорость: `V = 4Q/(π·d²)`
- Геометрический напор: `Hгеом = отметка_дикт − мин_уровень + высота_рамы`
- Потери: по длине `1000i·к·L` + местные; свободный напор на излив 1 м
- **Требуемый напор:** `Hтр = Hгеом + ΣHпот + Hизл`
- Сопротивление системы `S = (Hтр − Hгеом)/Q²`; кривая системы `H = Hгеом + S·Q²`
- Кривая насоса — паспортные точки Q–H вручную; пересечение = рабочая точка → марка насоса в ОЛ.

Ячейка A22 — свободный текстовый расчёт потерь под конкретный проект (разный во всех файлах).

В ОЛ_НАСОСНАЯ_СТАНЦИЯ встроен расчёт объёмов: `Vэф = Q/(4·пусков_в_час·n_раб)`, `Vмин = (Q/n)·t/60`, `hраб = 4·Vраб/(π·DN²)`, `hР = hраб + 0,3 + h_рамы + h_мин_насоса`, `Нподз = ROUNDUP((глубина_лотка + hР)·1000; −2)` → автоматически определяет глубину подземной части корпуса.

## 8. Экономика (итоговый блок — одинаков во всех файлах)

1. Σ чел.ч участка фитингов и участка РМУ (разделение по `"*изготов*"` в наименовании работ)
2. **ФОТ на ПЗР:** `часы_фитингов/11`, ROUNDUP до 0,1 × ставка ФОТ
3. **Ацетон:** `5% от массы формовки (кг)` × 109,4 ₽ (старое поколение: 126,5)
4. **СИЗ и РМ:** `ROUNDUP(часы_фитингов + ПЗР)` × 122 ₽ (стар.: 120) — в эталоне +302 к часам
5. **Накладные расходы:** `(часы_фитингов + ПЗР)` × **1584,73 ₽/чел.ч** (стар.: 1089,56)
6. **ИТОГО себестоимость с НДС** = Труба/муфта + Формовка + Работы ФОТ + Материалы на закупку + Прочие (3+4+5). НДС «зашит» в цены НН, отдельной строкой не выделяется.
7. **Наценка = 0,43** (константа во всех 6 файлах)
8. **Цена продажи** = `ROUNDUP(себестоимость × 1,43; −2)` (до 100 ₽)
9. **Рентабельность** = (Цена − Себест.)/Цена ≈ **30,07%**

Тираж: при кол-ве корпусов ≥ 2 итоги домножаются (колонки «за 1 корп. / за N корп.»).

### 9.2 Вес трубы, ПЭ трубы
- **GRP-труба** (162 строки, DN 300–3000): ключ `DN;PN;SN` → толщина стенки, вес кг/пм, параметры формовки, масса крышки. PN ∈ {0,6; 1,0; 1,6}, SN ∈ {2500; 5000; 10000}.

### 9.3 Для расчетов — инженерные матрицы
- Вес и толщина корпуса = f(Dу 1000–3000, L «до 3м»…«до 12м»)
- Масса формовки эллиптических днищ = f(Dн, L)
- Нормы патрубков = f(DN): мин. длина, масса формовки, масса фланца, крепёж
- Кол-во анкеров = f(Дн, глубина) по формуле всплытия (27 500 Н/анкер)

### 9.4 Прочие
- **Вспомогат. таблицы** — BOM-комплекты монтажных петель (усиленная/простая): состав и нормы расхода на узел.
- **для шапки** — геометрия ёмкости по 8 комбинациям Расположение×Установка×Шахта.
- **Справка АШУ Омега** — каталог шкафов управления (~220 позиций): маркировка, кВт, А, кол-во насосов, габариты.
- **Списки** — все enum для выпадающих списков (~50 списков: стадия, тип ШУ, вид НС, арматура, материалы труб, DN, PN, SN, типы патрубков/крышек/днищ, смолы, категории и т.д.).
- **Заявка** — закупочный документ: агрегирует непустые строки калькулятора (№, категория, наименование, ЕИ, кол-во, бюджетные цена и стоимость, дата закупки, отметка об исполнении).
- **Инструкции/Инструкции1** — регламент работы сметчика: заполнять только белые ячейки, не менять названия листов/категорий, не использовать «~», и т.п. (→ требования к валидации в вебе).

## 10. Сравнение 6 файлов — выводы

**Стабильно (зашивается в приложение как шаблон):**
- каркас 7 разделов калькулятора КНС и аналогичные каркасы ЕМК/колодца, порядок и подписи;
- все системные формулы: геометрия количеств, ФОТ-коэффициенты 0,28/0,56/1,0, ключ прайса, SUMIF-итоги;
- экономика: ПЗР=часы/11, ацетон 5%, накладные=часы×ставка, наценка 0,43, округление до 100 ₽;
- структура ОЛ (наборы полей) и справочник «Списки».

**Меняется от расчёта к расчёту (должно быть редактируемым):**
- все входы ОЛ (тип НС, DN, глубины, SN, патрубки, расход, напор, марка/кол-во насосов, флаги);
- число строк внутри разделов (прежде всего «Напорный трубопровод» и «Оборудование») — динамические таблицы;
- ручные overrides количеств (H) и цен (L), включая ручные арифметические выражения (`=1.55*2+2.88*2+…`);
- свободный текст гидравлического расчёта и точки кривой насоса;
- версия прайса НН (ставка ФОТ, накладных, цены) — критично версионирование.

**Расхождения с текущим ТЗ (v1.0):**
1. ТЗ описывает калькулятор как свободное дерево «связки→группы→подгруппы→строки». Реальный процесс — **шаблонная спецификация** с предрассчитанными количествами из ОЛ и точечными overrides. Свободное дерево нужно сохранить, но поверх него необходим механизм **шаблонов изделия** с формулами.
2. `PriceItem.lookupKey = "category:name"` неверен — реальный ключ **(категория, наименование, ЕИ)**.
3. Типы строк ТЗ (МАТ/РАБ/ФОТ/ЗАК) не совпадают с реальными категориями (16 шт.); ФОТ-автопересчёт должен идти от **массы (кг)** родительской строки с коэффициентами 0,28/0,56/1,0, а не только от количества РАБ.
4. Поля опросных листов в ТЗ (§5.6) — малая часть реальных; нужно расширение (см. дополнение ТЗ).
5. Отсутствуют в ТЗ: справочники весов труб и инженерных матриц, каталог АШУ, гидравлический расчёт, итоговый экономический блок, «Заявка на закупку», тираж корпусов, атрибут «вид НС» (КНС/ЛНС/ДНС — конструктивно одно изделие, разница только в среде стока).
