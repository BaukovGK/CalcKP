# НТТ Калькулятор

Расчёт стоимости изделий из стеклокомпозита (КНС, ЕМК, колодцы). Заменяет
Excel-книгу на 19 листов.

**Процесс:** опросный лист → материализация спецификации → тюнинг строк → КП →
согласование в коммерческом отделе (вне системы) → проработка инженером →
сметы и заявка на закупку.

```
backend/          Express 5 + Prisma 7 + PostgreSQL 16   :3000
ntt-calculator/   Vue 3 + Pinia + Vite                   :5173
doc/              ТЗ, механика, библиотека компонентов, план реализации
design_handoff_.../  прототипы и токены дизайна
```

## Запуск

### Требования

- **Node 20+** (проверено на 24.18)
- **PostgreSQL 16** на `localhost:5432`

### 1. Роль и база

Их нужно создать один раз. Пароль возьмите из `DATABASE_URL` в `backend/.env`:

```powershell
& "C:\Program Files\PostgreSQL\16\bin\psql.exe" -U postgres -c "CREATE ROLE ntt WITH LOGIN PASSWORD '<пароль>'"
& "C:\Program Files\PostgreSQL\16\bin\psql.exe" -U postgres -c "CREATE DATABASE ntt_estimates OWNER ntt"
& "C:\Program Files\PostgreSQL\16\bin\psql.exe" -U postgres -c "ALTER ROLE ntt CREATEDB"
```

`CREATEDB` нужен только в разработке: `prisma migrate dev` создаёт shadow-базу.

### 2. Конфигурация

```powershell
Copy-Item backend\.env.example backend\.env
Copy-Item ntt-calculator\.env.example ntt-calculator\.env
```

В `backend/.env` задайте `DATABASE_URL` и `JWT_SECRET`:

```powershell
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

### 3. Сборка и проверка

```powershell
.\verify.ps1
```

Скрипт делает всё с нуля и **проверяет результат**: зависимости → миграции →
сид справочников → сборка обоих приложений → тесты движка → smoke-проверка
живого API (логин, прайс, ставка ФОТ, веса труб, контрольное число).

Флаги: `-SkipInstall` · `-SkipSeed` · `-KeepRunning`.

### 4. Разработка

```powershell
cd backend;        npm run dev    # :3000
cd ntt-calculator; npm run dev    # :5173
```

**Учётные записи (только для локальной разработки):**

| Логин | Пароль | Роль |
|---|---|---|
| `admin@ntt.local` | `admin123` | ADMIN |
| `manager@ntt.local` | `manager123` | MANAGER |
| `engineer@ntt.local` | `engineer123` | ENGINEER |

## Docker

Проверено на Docker 29.6.1 / Compose v5.3.0. Поднимает стек с нуля: PostgreSQL
→ миграции → сид справочников → backend → nginx с собранным фронтом.

```bash
cp .env.example .env      # заполните POSTGRES_PASSWORD и JWT_SECRET
docker compose up --build
```

Приложение — на `http://localhost:${HTTP_PORT:-80}`. Сид идемпотентен и
выполняется при каждом старте, так что чистый том сразу даёт рабочую систему.

Полезное:

```bash
docker compose logs -f backend    # миграции и сид видно здесь
docker compose down               # остановить
docker compose down -v            # + удалить том с базой
```

## Развёртывание через GitHub

Репозиторий: `git@github.com:BaukovGK/CalcKP.git`. CI/CD — в
`.github/workflows/ci-cd.yml`.

**Первая публикация** (под аккаунтом-владельцем):

```bash
git push -u origin master
```

**CI** (на каждый push и pull request): typecheck фронта + 263 теста;
на бэке — `prisma migrate deploy` и сид против сервисного Postgres, затем
сборка. Ловит расхождение схемы и миграций до деплоя.

**Деплой по SSH** (автоматически при push в `master` после зелёного CI):
GitHub заходит на сервер и выполняет `git reset --hard origin/master` +
`docker compose up -d --build`. Требуется один раз:

1. На сервере: `git clone`, `cp .env.example .env` (заполнить
   `POSTGRES_PASSWORD`, `JWT_SECRET`, `PUBLIC_URL`), проверить `docker compose up`.
2. В репозитории **Settings → Secrets and variables → Actions** задать секреты:

   | Секрет | Назначение |
   |---|---|
   | `DEPLOY_SSH_HOST` | адрес сервера |
   | `DEPLOY_SSH_USER` | пользователь SSH |
   | `DEPLOY_SSH_KEY` | приватный ключ (публичный — в `authorized_keys` сервера) |
   | `DEPLOY_SSH_PORT` | порт SSH (необязательно, по умолчанию 22) |
   | `DEPLOY_PATH` | путь к каталогу репозитория на сервере |

`.env` в git не хранится (только `.env.example`) — он живёт на сервере и
переживает деплой. Для вкладки в Битрикс24 (ТЗ §10.1) `PUBLIC_URL` — домен с
валидным TLS.

## Справочники

Прайс, веса труб и списки извлекаются из мастер-шаблона
`ntt-calculator/doc/Шаблон 3.0.xlsx` — это исходная Excel-книга завода.

```powershell
cd backend; npm run refs:extract     # → prisma/seed-data/*.json
npm run db:seed                      # → в базу
```

Экстрактор падает при расхождении контрольных чисел (1040 позиций прайса,
162 GRP-трубы, 26 ПЭ, ставка ФОТ, вес DN3000) — лучше упасть, чем засеять мусор.

Прайс версионируется целиком: импорт через UI (`/prices`, роли ADMIN и BUYER)
создаёт новую версию и пишет `PriceHistory`.
