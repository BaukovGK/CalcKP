# Дизайн-бриф: НТТ Калькулятор (исходный)

Назначение: самодостаточное задание на проработку интерфейса. Первоисточники: ТЗ.md, Механика_калькулятора.md, Библиотека_компонентов.md.

## Продукт в одном абзаце

B2B-инструмент расчёта себестоимости и цены промышленных изделий из стеклокомпозита (насосные станции, ёмкости, колодцы) для завода ООО «НТТ». Заменяет Excel-книгу на 19 листов. Инженер заполняет опросный лист изделия — система материализует спецификацию из сотен строк (материалы, операции производства, труд) с формульными количествами и ценами из прайса; инженер точечно «тюнингует» строки; менеджер утверждает; итог уходит в Битрикс24. Ключевое ощущение: управляю изделием, а не таблицей.

## Пользователи

- ENGINEER — инженер-сметчик, знает изделие, привык к Excel. ОЛ → расчёт → тюнинг → на проверку. Ежедневно.
- MANAGER — руководитель направления. Проверка, рентабельность, утверждение/возврат. Несколько раз в неделю.
- BUYER — закупщик. Актуализация прайса, заявка на закупку. Еженедельно.
- TECHNOLOG — технолог-методолог. Редактор каталога компонентов и шаблонов (фаза 3). Редко.
- ADMIN — ИТ/руководство. Пользователи, аудит. Редко.

Все русскоязычные, десктоп, большие мониторы, многочасовые сессии. Мобильная версия не требуется; минимум — читаемость на ноутбуке 1366px.

## Контексты запуска (жёсткое ограничение)

1. Standalone SPA — полноэкранный режим.
2. Iframe внутри Битрикс24 (облако): страница приложения и вкладка в карточке сделки. Нельзя рассчитывать на всю высоту вьюпорта (resize через BX24 API), нет своих top-level навбаров, нет third-party cookies, вёрстка живёт в ~900–1200px. Одна вёрстка на оба контекста — навигация сворачиваемая.

Темизация: светлая и тёмная через CSS custom properties (data-theme на html), тёмная — по умолчанию. Все цвета — только токенами.

## Карта экранов

Login (только standalone; в Б24 — SSO) → Dashboard (проекты + поиск) → Проект (карточка + сетка единиц оборудования) → Опросный лист (модал-визард) → КАЛЬКУЛЯТОР (главный экран, 80% времени; подэкраны: Гидравлический расчёт, Заявка на закупку, История версий/снапшоты). Отдельно: Прайс-лист (BUYER/ADMIN), Каталог компонентов (TECHNOLOG, фаза 3), Админ.

## Статусная модель

DRAFT → CALC → REVIEW → APPROVED; REVIEW → CALC (возврат); любой → REJECTED (ADMIN). APPROVED — расчёт заморожен (снапшот), read-only. Красные строки блокируют CALC→REVIEW.

## Механика калькулятора (уточнённая в сессии)

Формулы подбора глубины (live в ОЛ):
- Vэф = Q·3,6/(4·10·n) м³ (10 пусков в час)
- Vмин = (Q·3,6/n)·5/60 м³
- hраб = 4·Vмин/(π·(DN/1000)²) м
- hР = hраб + 0,3 + 0,16 + 0,627 м
- Нподз = ROUNDUP((глубина_лотка_подводящего/1000 + hР)·1000, до 100 вверх) мм
- Контроль: Q=25,13 л/с, n=2, DN=3000, лоток 9910 → Нподз = 11 600 мм.

Труба корпуса: PN/SN не задаются пользователем изначально — продиктованы глубиной и требованиями заказчика (ТТ МВК, проезжая часть); возможность изменить вручную (чекбокс раскрывает параметры).

Арматура: задвижки устанавливаются на подводящие патрубки безнапорных трубопроводов (кол-во = кол-ву подводящих). Шаровые краны — на напорной линии (по техсхеме: раб+рез + коллектор; +1 при аварийном трубопроводе).

ФОТ-спутники: кол-во = масса родителя × k (k=0,28 для мех. дна, 0,56 для ламинирования), пересчёт при правке родителя, редактируемо.

Цена продажи = ROUNDUP(себестоимость × (1+наценка), до 100). Рентабельность = (цена − себестоимость)/цена.

## Реальные данные для мокапов

Изделие: КНС 3000×11900 мм (подземная часть 11 600 мм), 25,13 л/с; заказчик АО «ГК «ЕКС»; объект ГКБ №52, ул. Пехотная, 3; заявка 2406-118; насосы 2+1 VSL.100.55.4.5.0D; подводящий ПЭ DN250 ×1 (лоток 9910), напорный ПЭ DN150 ×2; корзина; МВК да; теплоизоляция 2000 мм; ШУ уличный, пуск плавный; датчики все.

Итоги-ориентир: себестоимость 11 603 440 ₽ → цена 16 593 000 ₽, наценка 0,43, рентабельность 30,1%. Прайс «НН v2 от 20.05».

## Визуальные требования

Числа: разряды пробелами, рубли без копеек в итогах, 2 знака в ценах, tabular-nums во всех таблицах. Строка таблицы ~32–36px. Цветовой язык состояний ячеек — единственный обязательный цветовой контракт. Палитра сдержанно-индустриальная. Иконография минимальная. Наименования длинные (ГОСТ) — колонка наименования доминирует, обрезка с тултипом недопустима для печатных форм.

## Приоритеты

1. Читаемость и скорость работы с таблицей 300+ строк.
2. Мгновенная связь «правка → итог».
3. Прозрачность источника каждого числа (доверие — главная валюта против Excel).
4. Работа в iframe Б24 без деградации.

## Антицели

Не «красивый дашборд с графиками» — рабочий стол сметчика. Не прятать данные за кликами. Не изобретать собственную навигацию внутри вкладки Б24. Не упрощать терминологию.
